# Homebrew tap

This directory is the Homebrew tap inside the `tailctl` source repository.
GoReleaser creates and updates `tailctl.rb` here after each stable release.
Do not hand-edit the generated cask; change `homebrew_casks` in `.goreleaser.yaml`.
Prereleases do not update the stable cask.

Once the project is public and the first stable release has completed:

```sh
brew tap davidcollom/tailctl https://github.com/davidcollom/tailctl.git
brew install --cask davidcollom/tailctl/tailctl
```

The workflow uses the normal same-repository `GITHUB_TOKEN` with `contents: write`.
There is no second repository or additional publishing secret. SHA-256 checksums,
architecture selection and shell completions are generated by GoReleaser.
See the root README for the public-release prerequisites and macOS signing details.
